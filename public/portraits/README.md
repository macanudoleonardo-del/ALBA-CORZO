# Portraits

Drop Alba's professional photos here with these exact filenames:

| File | Use | Ideal |
|---|---|---|
| `alba-hero.jpg` | Homepage hero | Vertical, head-and-shoulders, room around her |
| `alba-about.jpg` | About page | Vertical or square |

Then set `sections.portraits: true` in `src/lib/site.ts`.

Upload straight from GitHub if needed: repo → `public/portraits` →
**Add file → Upload files** → drag → Commit.

JPG or WebP, at least 1200px on the short edge. Next.js handles resizing,
format conversion and lazy-loading, so there is no need to optimise first.
